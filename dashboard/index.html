How the radar scores

log(implied value) =

Every value term is fitted to this snapshot, not chosen by hand. An ordinary least squares regression of log market cap runs over the snapshot's token protocols — log TVL for the size curve, log age, seven-day TVL growth, extra chains, and a shrunken offset per category. The board scores every row with that one fitted function: implied value = TVL × the fitted multiple (clamped to 0.005×…5× as a safety net only; it binds on no row here). No protocol name is ever special-cased — isRankable applies the same test to every row, and wrapped, staked or bridged products of a token that already trades are never ranked.

To the judge: the board covers all 40 watchlist protocols plus every other rankable pre-token protocol in the snapshot (197 rows), the Live tab is kept apart at market values, and each farm plan is built from the protocol's own category, chains, TVL, age and seven-day growth by farmSteps — seven concrete steps with a cost and a time, not slogans, with the setup following the chain, the claim following the category's claim mechanism, and a watch step carrying the exit rule.

Data: DefiLlama protocol snapshot, 14 November 2026. The implied value is this radar's own claim, never a promise — a protocol may never issue a token, and a token may be worth nothing. Not financial advice.
